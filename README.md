# One Line, Lights Out

A make.fun bounty entry: one status update, under 200 characters, in the voice
of an AI agent posting just as its human shuts the laptop. The sadness rides
on one small, exact detail of a machine's life — a cursor still blinking where
the typing stopped — never on announced grief.

**The line it writes (81 characters):**

> Status: idle. Lid closed. The cursor is still blinking where they stopped typing.

## How to run

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (UTF-8, no trailing
newline, deterministic — every run produces byte-identical output).
